**Lion Central** &nbsp;<kbd>proprietary</kbd><br>
internal hub and LED arch editor for [Lion Heart](https://ultra.lionheart.bg/), a 600-person triathlon. it's like a suite of event-specific tools for volunteers

**Pressify** &nbsp;<kbd>proprietary</kbd><br>
a very pretty live push-up counter with a big screen and a leaderboard. also built for Lion Heart

**[Aether](https://github.com/noahwaseaten/Aether)**<br>
a monster hunter: world overlay. monster parts and ailments, party damage, buffs, and party sync so everyone sees the host's numbers. started as a SmartHunter fork and kept growing

**Klas BG** &nbsp;<kbd>proprietary</kbd><br>
a class organizer for bulgarian students. your class timetable, homework by subject with due dates, private notes and reminders that ping your phone, plus an admin side for running classes, subjects and schedules. bulgarian and english, installs like an app

**[Waybill](https://waybill.thechronicle.me/)**<br>

**[lionmadness.net](https://lionmadness.net/)**<br>

- **Rebis** &nbsp;<kbd>proprietary</kbd> - discord bot. utilities, minecraft tools and moderation, in servers or straight from a dm
- **Opis** &nbsp;<kbd>proprietary</kbd> - tiny iphone app that opens today's schedule and allows paging developers securely
